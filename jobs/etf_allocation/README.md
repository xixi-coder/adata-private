# 宽基与行业ETF轮动

固定ETF池覆盖六只宽基和十只主要行业代表ETF。每月使用上月最后一个交易日收盘数据，本月首个交易日执行目标仓位。

- 宽基：上证50、沪深300、中证500、中证1000、创业板、科创50。
- 行业：证券、银行、消费、医疗、半导体、军工、新能源车、光伏、有色、煤炭。
- 过滤：至少200日历史，收盘高于120日均线，60日均线高于120日均线且保持上行，60日收益及风险调整动量为正，20日平均成交额不少于5000万元。
- 排名：`20日收益×45% + 60日收益×35% + 120日收益×20% - 20日年化波动×15%`。
- 组合：最多一只宽基和两只行业ETF。宽基和行业各占风险预算的一半；某组没有合格ETF时保留现金。沪深300站上200日均线且60日均线保持上行时风险预算80%，否则空仓。

运行：

```bash
python3 -m jobs.etf_allocation.run_daily
python3 -m jobs.etf_allocation.run_daily --send-email
```

工作流为 `.github/workflows/etf-rotation.yml`，工作日08:50运行，仅每月首个交易日给出调仓动作。
