# RSI极端反转红利低波ETF策略（v2定稿）

## 一、策略参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 标的 | 512890 红利低波ETF | 历史最长、流动性最好 |
| RSI周期 | 16 | Wilder平滑，300组网格扫描最优 |
| RSI算法 | Wilder RSI | 日线计算 |

| 交易频率 | 日频 | 每日收盘计算信号 |

---

# 二、策略核心逻辑

策略基于 RSI 指标判断市场极端情绪：

- RSI 极低：代表市场极端超卖，进行买入
- RSI 极高：代表市场情绪过热，进行分批止盈
- RSI 回落：重新进行仓位恢复

目标：

通过红利低波 ETF 的长期价值属性，捕捉市场恐慌与修复过程中的收益。

```

2020-02-03 疫情底
```

# 十一、策略伪代码

```python
daily:

    rsi = RSI(close, period=16)

    if position == 0:
        if rsi < 30:
            buy_all()

    else:
        if rsi > 92:
            sell_all()

        elif rsi > 82:
            sell(30%)

        elif rsi > 72:
            sell(20%)

    if rsi < 40:
        buy_all()
```
